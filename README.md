# Store Sales Prediction Using Machine Learning

## Project Overview
This project focuses on predicting retail store sales using Machine Learning techniques. The Kaggle Store Sales dataset is used to analyze historical sales patterns and develop regression models.

## Objectives
- Analyze historical retail sales.
- Identify sales patterns across product families and stores.
- Perform exploratory data analysis.
- Build machine learning regression models.
- Evaluate prediction performance.

## Dataset
Source: Kaggle – Store Sales Time Series Forecasting.

The project uses the training dataset (`train.csv`).

Dataset link:
https://www.kaggle.com/competitions/store-sales-time-series-forecasting/data
